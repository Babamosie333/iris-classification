Feature correlation heat-map

Pearson correlation between the 4 measurements. Petal length and petal width are almost perfectly correlated — together they carry most of the signal needed to separate species.

Pairwise feature scatter (pair plot)

Every feature plotted against every other, colored by species. Setosa (purple) separates cleanly from versicolor (teal) and virginica (rust) on almost every axis pair.

Feature distributions by species

Box plots per feature, split by species. Petal measurements show the cleanest separation; sepal width overlaps the most across classes.

Model accuracy comparison

Test-set accuracy for all three classifiers on the same 30-sample stratified hold-out (10 per species).

Confusion matrices

Rows = true species, columns = predicted species. A perfect model is a diagonal-only matrix — any off-diagonal cells are misclassifications.

Decision tree — learned rules

The exact splitting rules the depth-4 decision tree learned, in order. Read top to bottom: each indent level is one decision deeper.
